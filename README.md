# LGG-clustering

This repository contains scripts for generating ESM-2 protein embeddings, clustering proteins with UMAP and HDBSCAN, and identifying clusters enriched in strains classified as beneficial for skin health.

## Workflow

Run the scripts in this order:
###### esm2_embedding.py
#### cluster_embeddings.py
`enrichment_analysis.py`


### esm2_embedding.py

Edit the input and output paths before running. This script generates ESM-2 embeddings for each protein sequence and saves:

- `esm2_embeddings.npy`
- `gene_ids.csv`

The script can run on CPU or GPU. If CUDA is available, the model is moved to the GPU and converted to half precision to reduce memory use.

### `cluster_embeddings.py`

This script uses the ESM-2 embeddings, applies UMAP dimensionality reduction, and uses HDBSCAN to assign each protein to a cluster or noise.

Main output:

- `all_genes_with_clusters.csv`

### `enrichment_analysis.py`

This script compares protein clusters between strains classified as beneficial or non-beneficial for skin health. It uses two-sided Fisher’s exact tests, calculates fold changes, applies Benjamini–Hochberg FDR correction, and identifies clusters enriched in beneficial strains.

## Required files

- `esm2_embeddings.npy` — ESM-2 embeddings, with rows matching `gene_ids.csv`.
- `gene_ids.csv` — protein identifiers, strain names, and annotations.
- `all_genes_with_clusters.csv` — cluster assignments generated by `cluster_embeddings.py`.
- `strain_metadata.csv` — strain classifications with the columns:

```text
strain,beneficial
```

Use `beneficial = 1` for strains considered beneficial for the phenotype being studied and `beneficial = 0` for non-beneficial or control strains. In this project, classifications were based on literature relating to skin health. The file can be adapted for other organisms or phenotypes.

## Enrichment thresholds

Clusters are classified as beneficial-enriched when:

```text
log2 fold change > 0.5
q-value < 0.05
```

These values can be changed in `enrichment_analysis.py`.

## Main outputs

- `cluster_enrichment_analysis.csv`
- `cluster_statistics.csv`
- `beneficial_enriched_clusters.csv`
- `beneficial_hypothetical_clusters.csv`
- `lgg_beneficial_enriched_proteins.csv`
