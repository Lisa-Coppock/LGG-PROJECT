# LGG-clustering

This Github repository contains scripts for generating ESM-2 protein embeddings, UMAP and HDBSCAN clustering, and identifying clusters enriched clusters. In this project, the scripts were applied to bacterial proteins to identify clusters enriched in strains classified as beneficial for skin health based on a literature search.
This workflow requires an all_yes_no_proteins.faa FASTA file containing the predicted protein sequences for all bacterial genomes analysed. This file was generated by inputting the bacterial genomes into Prokka and is used as the input for ESM-2 embedding generation.


## Workflow

Run the scripts in this order:
`esm2_embedding.py`
`cluster_embeddings.py`
`enrichment_analysis.py`


#### esm2_embedding.py

Edit with own input file paths. This script will generate ESM-2 embeddings for each protein sequence and saves:

- `esm2_embeddings.npy`
- `gene_ids.csv`

The script can run on CPU or GPU. If CUDA is available, the model is moved to the GPU and converted to half precision to reduce memory use. This script uses the esm2_t36_3B_UR50D model, however can be changed depending on CPU/GPU memory.

#### `cluster_embeddings.py`

Edit with your own input file paths. This script uses the ESM-2 embeddings cerated previously, applies UMAP dimensionality reduction, and uses HDBSCAN to assign each protein to a cluster (or noise).



#### `enrichment_analysis.py`

This script compares protein clusters between strains classified as beneficial or non-beneficial for skin health. It uses two-sided Fisher’s exact tests, calculates fold changes, applies Benjamini–Hochberg FDR correction, and identifies clusters enriched in beneficial strains.

#### Required files

- `all_yes_no_proteins.faa` - output of Prokka
- `strain_metadata.csv` — strain classifications with the columns:

Use `beneficial = 1` for strains considered beneficial for the phenotype being studied and `beneficial = 0` for non-beneficial or control strains. In this project, classifications were based on literature relating to skin health. The file can be adapted for other organisms or phenotypes.


## Main outputs

- `cluster_enrichment_analysis.csv`
- `cluster_statistics.csv`
- `beneficial_enriched_clusters.csv`
- `beneficial_hypothetical_clusters.csv`
- `lgg_beneficial_enriched_proteins.csv`
